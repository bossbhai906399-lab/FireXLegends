FIREX LEGENDS - PHONE SETUP

1. Open your GitHub repository.
2. Go to Code -> Add file -> Upload files.
3. Upload the contents of this ZIP to the repository root.
4. IMPORTANT: keep .github/workflows/build-apk.yml in the same path.
5. Commit the changes to the main branch.
6. Open More -> Actions.
7. Open Build FireX Legends APK.
8. Wait for the green checkmark.
9. Open the successful run.
10. Scroll to Artifacts.
11. Download FireX-Legends-APK.
12. Extract it and install app-debug.apk.

If the workflow is red, open the failed run and send a screenshot of the red error step.
